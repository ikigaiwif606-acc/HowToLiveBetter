# 马来西亚改编计划

这是 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) 的马来西亚改编本。原文按中国大陆的法律和办事流程写。本仓库改成住在马来西亚的读者能照着做的版本。

核对日：2026-10-16。法律和政策只写核对过的官方文本。写不实的标 `TODO 待核实`，不编金额、条款号和 DOI。

分类只用四个词：

- **keep**：研究、习惯或算账方法不依赖中国机构，这一批不动。
- **localise**：动作和证据留下，热线、金额、例子改成马来西亚。
- **rewrite**：整条按中国制度写，改成马来西亚的对应做法。条号尽量不挪，免得后面的引用集体顺延。
- **remove**：马来西亚没有对应题目，而且不值得用别的题目占这个位置。这一轮还没有标 remove。兵役、户口、低保、特岗教师、公费师范生这类，计划是改写成当地的对应题，不留空号。

下面的表是计划，不是改写记录。第 1 到 34 节已经按马来西亚读者会照着做的部分改过。第 1、2、3、4、6、14、16、17、22、23、28、29、30、33、34 节的研究数字没动。docs/ 里几篇长文仍是中国清单，开头写了不要照做。

全表合计：keep 126，localise 210，rewrite 429，remove 0。共 765 条。
